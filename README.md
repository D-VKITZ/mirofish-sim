# MiroFish Simulator

MiroFish Simulator — Schwarmintelligenz Simulation.

## Features

- Multi-agent swarm simulation with configurable behaviors
- Real-time canvas rendering of agent movements
- Emergent behavior visualization and analysis
- Configurable parameters: speed, cohesion, separation, alignment
- Performance metrics and agent tracking

## Tech Stack

HTML5 Canvas · JavaScript ES6+ · No frameworks

## Quick Start

```bash
git clone https://github.com/D-VKITZ/mirofish-sim.git
cd mirofish-sim
# Open index.html in browser
```
